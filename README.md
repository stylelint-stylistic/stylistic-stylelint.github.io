# stylelint-stylistic.github.io

The documentation site of [`@stylistic/stylelint-plugin`](https://github.com/stylelint-stylistic/stylelint-stylistic/), served at <https://stylelint-stylistic.github.io/>.

Nothing here is written by hand. VitePress builds the site out of the Markdown the plugin's repository holds, and a workflow of that repository pushes the built site into the `gh-pages` branch of this one, which is what GitHub Pages serves. The default branch holds this file alone.

A page is edited where it is written, in [the plugin's repository](https://github.com/stylelint-stylistic/stylelint-stylistic/): a rule's page is that rule's `README.md`, and the guides are the files of `docs/`.
